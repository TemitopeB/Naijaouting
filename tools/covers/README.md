# Category covers (v3)

The 23 category covers in `/covers/` are drawn by code, not generated by AI.

- `art.py`: drawing kit (light, shadow, haze, figures in gele, fila, agbada and ankara, umbrellas, danfo, palms, Aso-oke trim).
- `scenes.py`, `scenes2.py`: one function per category.
- `r12.js`: renders every SVG at 1200 × 1200 px.

To change a cover: edit its scene, then

    python3 scenes.py && python3 scenes2.py      # writes svg/<slug>.svg
    node r12.js                                  # writes p12/<slug>.png (needs Playwright)

then save each PNG as WebP (quality 80) into `/covers/<slug>.webp` and bump `VERSION` in `sw.js`.
Keep the subject in the middle and the corners calm (date bottom-left, tags top-left, buttons top-right).
